# GitHub에서 Render로 배포하기

이 경로는 터미널 없이 **누구나 조회하고 운영자만 갱신·기록하는** PIONEER를 게시할 때 사용합니다.
Render가 외부 HTTPS를 담당하고, 앱 안에서는 공개 읽기 화면과 비밀번호로 보호된 운영 화면을 분리합니다.

## 배포 전에 확인할 것

- 기본 `render.yaml`은 비용 없는 미리보기 구성을 요청합니다. 파일시스템이 임시이므로 Render가 인스턴스를 교체하거나 재시작하면 운영자 입력과 갱신 결과가 사라질 수 있습니다.
- GitHub 저장소에는 공개 가능한 시작 자료만 들어갑니다. 운영자 비밀번호은 GitHub 파일에 저장하지 않고 Render 화면에서 직접 정합니다.
- 운영자 아이디의 기본값은 `admin`입니다. 비밀번호는 12자 이상, UTF-8 기준 72바이트 이내로 정합니다.
- 이 간편 구성은 한 컨테이너에서 공개/운영 화면을 나눕니다. 별도 서버와 도메인을 운영하는 구성은 [배포 안내](deployment.md)를 사용합니다.

## 화면에서 하는 순서

1. 이 프로젝트 파일을 GitHub 저장소 최상위에 올립니다. GitHub 첫 화면에서 `render.yaml`과 `Dockerfile.render`가 보여야 합니다.
2. Render에 GitHub 계정으로 로그인한 뒤 아래 주소를 엽니다.
   `https://render.com/deploy?repo=https://github.com/lcy010427-bot/pioneer`
3. `PIONEER_ADMIN_PASSWORD`에 새 비밀번호를 입력합니다. 이 값은 채팅이나 GitHub에 올리지 마세요.
4. 요금이 `Free`인지 확인한 뒤 배포를 시작합니다. 유료 항목이 보이면 진행하지 말고 설정을 다시 확인합니다.
5. 완료된 웹 주소를 열면 공개 조회 화면이 나옵니다. 화면 위의 **운영자 로그인**을 누르고 아이디 `admin`과 정한 비밀번호로 로그인합니다.

## 데이터와 운영

처음 시작할 때 `public-data/starter.sqlite.gz`의 공개 시작 자료를 임시 파일시스템에 복원합니다. 시작 자료에는 정해진 관심 물질 목록 대신 5년·1년·최근 3개월 환경 문헌 스크리닝 결과와 근거 문헌 정보가 들어 있습니다. 운영자 입력·평가·내부 로그·원문 사본은 없습니다. 무료형에서 재시작으로 자료가 초기화되면 같은 시작 자료로 돌아옵니다.

운영자 입력과 갱신 결과를 계속 보존해야 할 때에는 Render의 유료 영구 디스크를 붙이거나 별도 서버 구성을 사용해야 합니다. 유료 전환은 Render가 표시하는 현재 금액을 확인한 뒤 별도로 결정하세요.

Render가 제공한 주소 외에 별도 도메인을 연결하면 `PIONEER_PUBLIC_ORIGIN`을 그 `https://` 주소로 추가해야 합니다. 배포 후 `/healthz`가 정상인지 확인하고, 중요한 운영 기록은 정기적으로 내보내 보관하세요.
