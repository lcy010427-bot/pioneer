# 설계와 기준 상태 · 0.2

## 승인 범위

사용자는 신규 구현과 로컬 검증 후, 중간 승인 요청 없이 나머지 개발을 진행하되 **배포하지 말 것**을 지시했습니다.
이 지시에 따라 로컬 연구 작업 흐름과 검토·평가 도구를 구현했습니다. 소프트웨어 개발 완료와 방법론·연구 결과의
전문가 확정을 구분합니다. 실제 사람이 수행해야 하는 평가·근거 판단을 Codex가 대신 완료한 것으로 표시하지 않습니다.

## 구성

- `core.py`: 고정/편입 관심 목록, 검색식, 수집 실행별 스냅샷, 서지 정규화, 원본 집계.
- `analysis.py`: 결정적 키워드 규칙·근거 위치·부정/잠정/리뷰 표시, 지도, 후속 확인 질문, 민감도 시나리오.
- `research.py`: PubChem 캐시, 공개 원문 확인·분석, 후보 검토함·편입, append-only 검토,
  보완 검색, 관계 제안, 공통 기간 비교, 과업 평가, CSV·백업·무결성 검사.
- `__main__.py`: CLI 및 동일 출처의 로컬 API. 임의 URL을 요청받지 않으며 쓰기 작업을 직렬화.
- `web/`: 외부 CDN·트래킹·AI 호출이 없는 한국어 웹 화면, 키보드 조작·모바일 레이아웃.

## 저장과 재현

기존 `chemicals/runs/papers/metadata`를 보존하고 `identities/candidates/decisions/fulltexts/followups/
manual_relations/evaluations/external_log`를 추가했습니다. 현재 스키마는 3이며 반복 초기화는 기존 자료를 지우지 않습니다.
수집 이전에 백업을 만들었고 확장 완료 후에도 SQLite backup API로 백업·재열기를 검사했습니다.

원본 명칭은 그대로 보존합니다. CID 하나가 나와도 자동 병합하지 않고, 후보 편입은 검토자·사유를 요구합니다.
관심 목록에 같은 CID가 있거나 매핑이 모호하면 새 물질로 편입하지 않습니다. 이름 탐지는 상위 30개로 제한하고
후보 생성 범위·규칙의 오류 가능성을 보여줍니다. 이전 후보·검토 이력은 삭제하지 않습니다.

검색식과 수집 실행은 별개입니다. 기존 실행은 watchlist-v1 표시를 보존하고 이후 실행부터 동의어 JSON의 해시를
query_version에 기록합니다. 원본 차트는 검색 일치 건수를 표현하며, 검토 제외로 원본 집계를 변경하지 않습니다.
검토 제외는 근거 지도·질문에서 반영합니다. 마지막 complete 스냅샷을 우선하고 없을 때 partial만 표시합니다.
오류나 한도 도달을 0건으로 바꾸지 않습니다. 강제 종료 시 running 이력이 남을 수 있으며 다음 수집은 새 실행입니다.

공개 원문은 MED/AGR 등 저장 식별자→공식 메타데이터→PMCID→원문 API로 연결합니다. XML의 PMCID·DOI와
라이선스를 확인하고, 본문 절·문단·내용의 해시를 저장합니다. references는 본문 추출에 포함하지 않습니다.
제목·초록·원문 문장별 위치와 규칙 버전이 다르며, 미검토 결과를 실제 측정·기전 확립으로 승격하지 않습니다.

리뷰·정정·철회 표시 정보의 한계를 표시하고, preprint/정식판·동일 연구자료를 완전히 연결했다고 주장하지 않습니다.
문헌 수·독립 연구 수·관계 진술 수를 구분하고 관계 문헌의 DOI 중복도 제거합니다.

보완 검색은 원래 기간 밖에서 기존 답을 찾을 수 있게 물질·endpoint로 넓히며, 매질 단어로 과도하게 제한하지
않습니다. 이 의미를 화면에 표시합니다. 완전 수집된 실제 보완 검색 없이 질문을 followup_complete로 표시하지 못합니다.
이 상태도 확정 연구공백이나 과학적 타당성 승인이 아닙니다.

검토 기록은 덮어쓰지 않습니다. 사용자 입력의 주체·사유·시각을 보존하며, 자동 검사는 marked validation copy에만 씁니다.
실제 DB의 검토·평가는 0건입니다. 평가 도구는 과업 순서, 시작/완료 시각, 실제 대조한 분모와 올바른 건수,
수정·검증 내역, 평가자, 운영상 효용 평점을 기록하며 실제 참여 없이 결과를 생성하지 않습니다.

## 남은 과학적·외부 한계

규칙 기반 화학물질 명칭·맥락 추출의 정밀도/재현율, hot 판정 임계값, 연구공백·관계 해석의 타당성,
구조 계산·read-across, 실제 사용자 효용은 검증되지 않았습니다. CTD 연결 데이터는 네트워크 접근 차단으로
미수집입니다. PubChem 명칭 매핑만 실제 확인했습니다. 잠정 기준은 사람이 검토해 바꿀 수 있고 실행 조건과 함께
내보내지만, 이 도구가 자동으로 연구 의사결정을 승인하지 않습니다.

개발과 로컬 검증은 중간 승인 없이 마쳤으며, 미결정인 과학적 기준·검토 결과를 임의로 확정하지 않았습니다.
공개 배포와 새 클라우드 작업에서의 복원은 실시하지 않았습니다.
