# 사용자 과업 평가 절차

**실제 참여자 평가: 미실시.** 아래는 준비된 절차와 앱 기록 도구의 사용 방법입니다.
자동 UI 검사로 만든 참여자·점수·검토 기록은 검증용 복제 DB에만 있으며 실제 효용 평가에서 제외해야 합니다.

## 같은 과업·세 조건

조건은 수작업 문헌검색, 일반 ChatGPT 활용, PIONEER 활용으로 나눕니다. 같은 비교 대상·기간·허용 자료원·시간
조건을 제공하고 실제로 동일한 연구 과업을 수행하게 합니다. PIONEER의 현재 2024–2025 공통 자료 범위와 맞추되,
실제 연구 목적에 맞는 범위인지는 연구자가 먼저 검토합니다. 접근 권한·사전지식·연구 경험도 별도 기록합니다.

과업 예시:

1. 두 물질의 관심 변화와 그 관찰을 뒷받침하는 논문을 찾아 선정 사유를 작성.
2. 같은 매질·모델·endpoint에 관한 근거와 비교가 성립하지 않는 조건을 설명.
3. 확정 연구공백으로 단정하지 않고 보완 검색·핵심 논문·후속 검토 질문을 제시.

관계망이 효용을 높이는지 보려면 관계망 없는 기본 정보 화면과 관계망 제공 화면을 별도 조건으로 비교합니다.
작은 파일럿 결과를 전체 연구자·모든 물질·실제 위험 발견 성능으로 일반화하지 않습니다.

## 순서와 시간

참여자별 조건 순서를 균형 있게 배정하거나 무작위화하고 배정 근거를 남깁니다. 같은 과업 반복으로 생기는
학습 효과를 줄이기 위해 난도가 비슷한 다른 사례를 교차 배정합니다. 이 배정은 앱이 자동 수행하지 않으므로
프로토콜 기록으로 보관합니다. 단순히 ‘세 번째 조건이 빨랐다’는 이유로 도구 효과를 주장하지 않습니다.

앱의 기준·기록 탭에서 참여자 구분명, 조건, 과업을 입력하고 시작합니다. 시간을 측정할 때 문헌 읽기·원문 검증·
오류 수정·추천 수정 시간까지 포함합니다. 완료 버튼을 누르면 시작/종료·경과 시간·실행 순서를 저장합니다.
외부 사정으로 중단하거나 이탈한 세션은 완료시키지 말고 사유를 따로 기록합니다.

## 검증과 효용

가능하면 조건을 모르는 별도 평가자가 동일한 지침으로 산출물을 평가하고 불일치를 기록합니다.
평가할 항목:

- 인용이 실제 주장과 일치하는가, 실제 문헌·원문 위치가 존재하는가.
- 물질·매질·종·생애단계·농도·노출기간을 혼동하지 않는가.
- 관심 증가·중요성·위해성을 구별하는가.
- 기존 답·반대 근거·검색 범위 밖 근거를 놓치지 않았는가.
- 비교 물질의 근거 전이가 적절한가. 조건 차이와 한계를 명시했는가.
- 후속 질문이 구체적이고 실제로 수행 가능한 검토 행동으로 연결되는가.

앱에 직접 대조한 주장·인용의 총 건수와 그중 정확한 건수를 입력합니다. 분모 0은 정확도 N/A입니다. 이 비율은
추출 전체의 precision/recall·탐지 성능이 아닙니다. 정답 라벨·대조 대상·표본 선정 방식을 별도 보존해야 합니다.
효용 1–5는 운영상 평점이며 검증된 척도가 아닙니다. 점수와 함께 이유·누락·수정·검증 내역·평가자 구분명을 기록합니다.

## 과학적 출력의 별도 검증

추세 탐지, 문헌 검색, 물질 식별, 맥락 추출, 관계 추출, 후속 질문의 적절성은 각각 다른 평가입니다.
검토 표본에는 부정 표현, 리뷰·서론 언급, 원문 미접근, 물질군·약어 충돌, 단순 공동 언급, 변환 조건의 차이,
상충 결과, 0건 분모, 낮은 건수의 증가, 소재 연구만 증가하는 사례를 포함합니다.
개발 사례와 최종 성능 평가 사례를 분리하고, 전문가 확인 전에는 인간 검증 완료라고 쓰지 않습니다.

## 보고

실제 참여자 수·실시 조건·미완료·미실시를 구분하고, 시간 분포와 근거 정확성·관련성·질문의 효용을 함께 보고합니다.
실험 없이 효용 개선·만족도·시간 절감 수치를 만들지 않습니다. 현재는 도구 구현과 자동 검증만 완료했습니다.
