## 검사 환경과 실제 배포의 구분

검사는 임시 Compose 프로젝트의 빈 실자료 DB와 명시적인 가짜 입력만 사용했습니다.
실제 `.data/pioneer.sqlite`를 서비스 볼륨으로 연결하거나 검토/선정 입력을 쓰지 않았습니다.
TLS는 임시 Caddy 내부 CA, 공개 바인딩은 **127.0.0.1:19443**뿐이며 검사 후 컨테이너·검사 볼륨을 정리했습니다.
실제 공인 DNS·80/443 포트·공인 인증서 발급에는 변경을 가하지 않았습니다.

운영 도메인의 공인 인증서 발급·실서버 방화벽/DNS·실제 네트워크의 자료원 접근·장시간 부하/백업 주기는 배포 환경에서 확인할 사항입니다.
동시 사용자 규모에 대한 벤치마크나 고가용성/다중 계정/SSO를 검증한 결과가 아닙니다.
기존 과학적 판단 기준·인간 평가의 미확정 상태도 그대로입니다.
